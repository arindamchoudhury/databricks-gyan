# Platform Release Notes — June 2026

> **Source:** [docs.databricks.com/aws/en/release-notes/product/2026/june](https://docs.databricks.com/aws/en/release-notes/product/2026/june)
> **Added:** 2026-06-11

---

## Data Engineering highlights

### Lakeflow & Pipelines

**`@dp.update_flow` decorator (GA)**
Enables update output mode writes with stateful aggregations in Lakeflow Spark Declarative Pipelines — previously in preview.

**External streaming tables/materialized views access (Public Preview)**
External Delta and Iceberg clients can now read streaming tables and materialized views managed by a pipeline via Unity Catalog and Iceberg catalog REST APIs, without copying data.

**Table update triggers — expanded sources (Beta)**
Now monitors Delta Sharing and system tables in addition to local tables (Databricks-to-Databricks only).

### Lakeflow Connect — new managed connectors (Beta)

- Pendo (product analytics)
- Zoom Logs (user activity, admin operations)
- RabbitMQ (streaming messages → streaming tables)
- Slack Access and Integration Logs

**SharePoint enhancement:** Now handles structured file ingestion (CSV, JSON, XML, Excel, Parquet, Avro, ORC), file metadata, schema evolution, and schema hints.

**Source lineage for Lakeflow Connect (GA)**
Managed ingestion pipelines now automatically record source lineage from source → destination tables in Unity Catalog.

### Unity Catalog & Governance

**External lineage (GA)**
Register external assets (Salesforce, MySQL, Tableau, Power BI) in Unity Catalog so a single lineage graph spans your full data flow.

**Column popularity in Catalog Explorer**
Shows number of queries reading each column — useful for understanding hot columns and pruning unused ones.

**Identity federation enabled by default** for all new workspaces (including non-UC workspaces).

### Platform changes

**Delta Sharing → OpenSharing**
"Delta Sharing is now OpenSharing" — open standard on GitHub (opensharing.io). Same protocol, new name.
> ⚠️ **Learning path note (A7):** The topic "Lakehouse Federation & Delta Sharing" should now refer to OpenSharing. API and functionality unchanged.

**Vector Search renamed to AI Search**
Now supports full-text search indexes without vectors/embeddings.

### Compute

**Inbound Private Link for performance services (GA)** — for Lakebase Autoscaling and Zerobus Ingest.

**Workspace file write performance** (Runtime 17.1+)
File writes, deletes, and metadata ops are batched and flushed in background — reduces latency for Git operations.
