# Databricks SQL — 2026 Release Notes

> **Source:** [docs.databricks.com/aws/en/sql/release-notes/2026](https://docs.databricks.com/aws/en/sql/release-notes/2026)
> **Current channel:** 2026.10 | **Preview channel:** 2026.15
> **Added:** 2026-06-11

---

## June 2026

**UNIQUE constraints (Public Preview)**
`UNIQUE` constraints on UC Delta tables. Foreign keys can reference UNIQUE columns. `RELY` option enables join elimination and DISTINCT simplification on Photon.

---

## May 2026 (version 2026.15 preview)

**NULL struct preservation**
NULL struct in source now stored as NULL in target (INSERT/MERGE/streaming with schema evolution). Previously materialized as non-null structs with all-NULL fields.
> ⚠️ **Breaking (DBR 18 / serverless 18.2):** Downstream consumers comparing NULL struct fields will see behavior change.

**VOID type support in Delta**
Delta tables now support VOID columns (previously skipped in reads/time travel).

**LEFT OUTER JOIN LATERAL bug fixed**
No longer drops rows (was a correctness bug). Revert via config if needed.

**SQL UDF dependency validation**
Prevents unauthorized access in Unity Catalog.

**`CREATE OR REPLACE TEMP TABLE`**
New DDL syntax now supported.

**`DESCRIBE HISTORY` includes write option flags**
Now shows `isDynamicPartitionOverwrite`, `canOverwriteSchema`, `canMergeSchema`.

**Native data profiling (GA)** — May 1
Column profiling statistics directly in SQL editor results sidebar.

---

## April 2026 (version 2026.10)

**`agg()` function**
Alias for `measure()` in metric views.

---

## March 2026 (version 2026.10 preview)

**SQL scripting (GA)**
Procedural logic (cursors, stored procedure patterns) now generally available.

**Observation metrics**
Errors during collection no longer fail queries.

**Geospatial improvements**
`ST_Difference`, `ST_Intersection`, `ST_Union` new implementation — ~2x faster; now on Photon.

New functions: `st_estimatesrid`, `st_force2d`, `st_nrings`, `st_numpoints`.

**Vector aggregate functions:** `vector_avg`, `vector_sum`.

**Window measures:** period-over-period via offset field; anchor row inclusion/exclusion.

**Sketch functions:** `approx_top_k_*`, tuple sketch family (aggregate, estimate, union, intersection, difference).

**SQL cursor support**
`DECLARE CURSOR`, `OPEN`, `FETCH`, `CLOSE` in compound statements.

---

## February 2026 (version 2025.40)

**SQL scripting (GA)** — full procedural logic.

**Parameter markers everywhere**
`:param` and `?` markers now work in DDL, column types, comments.

**`IDENTIFIER` clause expansion**
Nearly all identifier contexts now accept dynamic identifiers.

**Theta sketch functions:** `theta_sketch_agg`, `theta_union_agg`, `theta_intersection_agg` + scalar variants.

**KLL sketch functions** for approximate quantile computation.

**`BITMAP_AND_AGG`** aggregate function.

**Geospatial additions:** `st_azimuth`, `st_boundary`, `st_closestpoint`, EWKT parsing.

**Performance improvements:**
- Improved caching for queries with row filters/column masks.
- Photon for `st_isvalid`, `st_makeline`, `st_makepolygon`.

**Delta operations:**
- `FSCK REPAIR TABLE` includes metadata repair by default.
- `DESCRIBE TABLE` output includes metadata column.
- Partition columns materialized in Parquet files.
- Time travel restricted beyond `deletedFileRetentionDuration` — now hard error.
