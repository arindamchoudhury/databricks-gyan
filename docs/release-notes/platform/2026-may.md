# Platform Release Notes — May 2026

> **Source:** [docs.databricks.com/aws/en/release-notes/product/2026/may](https://docs.databricks.com/aws/en/release-notes/product/2026/may)
> **Added:** 2026-06-11

---

## Data Engineering highlights

### Runtime

**Databricks Runtime 18.2 (GA)** — Apache Spark 4.1.0. Stable for production.
**Databricks Runtime 18 (Beta)** — unified release notes format; features now ship as dated updates.

### Lakeflow Pipelines

**Real-Time Mode (Public Preview)**
Sub-5ms end-to-end latency for operational streaming via new `update_flow` decorator — supports stateful aggregations without watermarks.

**Sinks (GA)**
Write transformed pipeline data to Delta tables, Kafka topics, Azure Event Hubs, and custom Python sources with append flows.

**Pipeline parameters (Beta)**
Define key-value pairs at pipeline level; reference with named parameter syntax in SQL.

**Lakeflow Pipelines Editor (GA)**
Agent-first development combining Genie Code chat with pipeline graph and metrics visualization.

**Lakeflow Designer default-on**
Now enabled for all workspace tiers with AI operator suggestions, git integration, and configurable sample sizes.

**Environment versions (Beta)**
Decouple pipeline Python runtime from DBR upgrade cycle by pinning language versions and libraries.

**Materialized view refresh policies (GA)**
Control incremental vs full refresh timing; use `EXPLAIN CREATE MATERIALIZED VIEW` to verify incrementalization before defining.

**Unity Catalog managed Iceberg (GA)**
Create and manage Iceberg tables in UC with liquid clustering, predictive optimization, materialized views, and streaming tables support.

### Lakeflow Connect

**Query-based connectors (GA)**
Ingest from Oracle, Teradata, SQL Server, MySQL, MariaDB, PostgreSQL, and Lakehouse Federation sources without CDC configuration.

**New Beta connectors:** Google Drive, Outlook, GitHub, Smartsheet.

### Jobs & Monitoring

**SQL Alert Task (Public Preview)**
Evaluate Databricks SQL alerts as pipeline job steps; evaluation state passed to downstream tasks.

**Unified Runs List (GA)**
Single view for all job and pipeline runs with real-time filtering by status, time, user, run ID, and error codes.

### Developer Tools

**Databricks CLI (GA)**
Now generally available with user-to-machine tokens stored in OS-native secure storage.

**YAML auto-update**
UI edits to jobs and pipeline settings automatically update bundle YAML — bidirectional sync between UI and code.
> **Learning path note (A5):** Key new workflow — edit in UI, changes reflected in YAML, commit to Git.

**Bundle resource editing (GA)**
Seamless sync between UI and code-based bundle configurations.

### Unity Catalog

**Catalog Commits (GA)**
Multi-statement, multi-table transactions; integrates with streaming tables, Delta Sharing, Zerobus, Lakeflow Connect, Unity AI Gateway, MLflow, and job triggers.

**Cross-engine ABAC (Beta)**
External engines can read UC managed tables with server-side row filters and column masks enforced.

### Compute / Serverless

**Serverless notebook timeout settings**
Workspace admins configure default execution timeouts (default: 2.5 hrs) with per-notebook overrides via `spark.databricks.execution.timeout`.

**`%uv pip` magic command**
Faster package installs in serverless notebooks (environment version 5+).

**Serverless general compute for standalone materialized views/streaming tables (Beta)**
Create MVs and streaming tables from notebooks without a pipeline cluster.
