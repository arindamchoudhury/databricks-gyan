# DIP-Dummies — The Data Intelligence Platform For Dummies

> **Authors:** Ari Kaplan & Amit Kara (contributing writer Stephanie Diamond) · **Publisher:** John Wiley & Sons · **Edition:** 2nd Databricks Special Edition (© 2026) · ISBN 978-1-394-39641-2
> **Type:** book (vendor overview / marketing booklet, ~45 pp.)

A short Databricks-sponsored "For Dummies" booklet that pitches the **Data Intelligence Platform** — Databricks' framing of an AI-augmented lakehouse. Conceptual, no code. Value is the **product-component taxonomy** (Ch 3) and the **agent/AI story** (Ch 4); the rest is business-benefit framing.

> 📌 **Currency:** the booklet is © 2026 and tracks the current platform — Agent Bricks, Lakebase, Lakeflow + Spark Declarative Pipelines, AI/BI Genie, Databricks Apps, MCP, Iceberg. One naming note: it still says **"Delta Sharing"**; per project convention this is now **OpenSharing** (Linux Foundation, June 2026). Flagged inline.

> 📎 **Overlaps:** Ch 2–3 restate the lakehouse pitch in [[ch01-getting-started-with-databricks]] (DCDE-SG) and the personal book [[ch01-databricks-platform-workspace]]; the blog note [[what-is-a-lakehouse]] covers the same lakehouse-vs-warehouse-vs-lake ground in more depth.
