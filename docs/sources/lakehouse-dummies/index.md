# Lakehouse-Dummies — The Data Lakehouse For Dummies

> **Authors:** Ari Kaplan & Amit Kara · **Publisher:** John Wiley & Sons · **Edition:** 2nd Databricks Special Edition (© 2026) · ISBN 978-1-394-39663-4
> **Type:** book (vendor overview / marketing booklet, ~29 pp.)

A short Databricks-sponsored "For Dummies" booklet that makes the case for the **data lakehouse** — open, unified, scalable, governed — and then layers Databricks' **Data Intelligence Platform** on top. Conceptual, no code. It's the lakehouse-first companion to the same authors' [[index]] *Data Intelligence Platform For Dummies* (DIP); this one leads with the architecture, that one leads with the AI/intelligence story.

> 📌 **Currency:** © 2026, tracks the current platform — Lakebase, Agent Bricks, AI/BI Genie, Spark Declarative Pipelines, Unity Catalog OSS, Apache Iceberg, Databricks Apps, MLflow. One naming note: it still says **"Delta Sharing"**; per project convention the open protocol is now **OpenSharing** (Linux Foundation, June 2026). Flagged inline.

> 📎 **Overlaps:** this booklet covers nearly the same ground as DIP-Dummies, only ordered architecture-first. The warehouse-vs-lake-vs-lakehouse argument is told with more rigor in [[ch01-getting-started-with-databricks]] (DCDE-SG §1) and [[what-is-a-lakehouse]] (blog); platform components map to [[ch03-databricks-platform]] (DIP) and the personal book [[ch01-databricks-platform-workspace]].
